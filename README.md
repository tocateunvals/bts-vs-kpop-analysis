# Análisis Comparativo: BTS vs Otros Artistas de K-pop y Pop

## 📋 Descripción
Trabajo Integrador Final del curso de Data Science (UTN.BA). Análisis exploratorio y comparativo de las características de audio de la discografía de BTS en contraste con otros artistas de K-pop y Pop.

## 🎯 Objetivos
1. Analizar la evolución de las características de audio de BTS a lo largo de su carrera.
2. Comparar las propiedades musicales de BTS con otros artistas.
3. Identificar qué características se asocian con una mayor popularidad.

## 📂 Estructura del Proyecto
- `data/`: Datos crudos y procesados
- `notebooks/`: Jupyter notebooks con el análisis paso a paso
- `outputs/`: Gráficos y reportes generados
- `src/`: Funciones auxiliares reutilizables

## 🛠️ Tecnologías
- Python 3.10+
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn

## 📊 Datasets
- Kpop Artists and Full Spotify Discography (Kaggle)
